# P9.2 — Pixel time-series chart

P9.2 — Pixel time-series chart
Add a click-to-inspect feature to Explorer Mode: clicking any pixel on the deformation
layer fetches that pixel's raw time series from a new backend endpoint (add
GET /timeseries?lat=&lon=&layer= to the API if P7.1 didn't already cover a per-pixel,
not just per-cluster, query) and renders it as a line chart (Recharts) showing
displacement over time, with the fitted velocity line overlaid. Handle the case where
the clicked pixel was coherence-masked (no valid time series) with a clear "no reliable
signal at this location" message rather than a blank or broken chart.

Acceptance criteria: clicking on a real, valid pixel produces a chart with real,
correctly-ordered time-series data matching the pipeline's stored values; clicking a
masked pixel shows the explicit no-data message, never a silently empty chart.
