# P10.2 — Reproducibility export

P10.2 — Reproducibility export
Add an "Export for reproducibility" button in Research Mode that downloads a small
package for the selected AOI/date range: a JSON file with all the processing parameters
used (coherence threshold, velocity/acceleration thresholds, confidence model weights,
CRID/processor versions), and a minimal Jupyter notebook stub (a real .ipynb file, not
a text description of one) that shows how to rerun the P2/P3 pipeline functions on a
fresh date range using those exact parameters. This does not need to be a full
one-click rerun system — it needs to be genuinely useful to a researcher who wants to
verify or extend your method, which is an explicit requirement in the original
challenge brief.

Acceptance criteria: the downloaded notebook actually runs (test it in a fresh
environment) against the documented pipeline functions without needing undocumented
manual fixes.
