# P5.1 — Glacier motion event detection

P5.1 — Glacier motion event detection
Using the GOFF-derived velocity rasters from P2.3, write a change-detection function
analogous to P3.1/P3.2 but tuned for glacier motion: instead of flagging "accelerating"
pixels, flag pixels whose velocity has changed significantly (documented threshold)
between two time windows, since glacier speed-up is the relevant precursor signal here
rather than slope acceleration. Produce Change Passport objects with hazard_type set
to "glacier_motion", reusing the same confidence-scoring function from P3.3 with
component definitions adapted where necessary (state any adaptation explicitly in a
code comment).

Acceptance criteria: at least one real glacier-motion Change Passport is produced from
real GOFF data over or near the flagship AOI, schema-valid against the same JSON Schema
as the deformation passports.
