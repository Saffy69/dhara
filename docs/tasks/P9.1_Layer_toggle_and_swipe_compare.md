# P9.1 — Layer toggle and swipe compare

P9.1 — Layer toggle and swipe compare
Build an Explorer Mode page reusing the same MapLibre map instance pattern as Story
Mode, adding: independent toggle checkboxes for each available layer (deformation,
glacier motion, water extent, rainfall), and a before/after swipe comparison widget
that lets the user drag a slider to compare the same layer at two user-selected dates.
Allow the user to draw a custom bounding box (using MapLibre's draw plugin or an
equivalent) and see a count of Change Passports intersecting that custom area.

Acceptance criteria: toggling any single layer on/off does not break or hide any other
active layer; the swipe comparison visibly and correctly shows two different real dates
of the same underlying data, not two copies of the same date.
