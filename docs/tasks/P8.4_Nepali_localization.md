# P8.4 — Nepali localization

P8.4 — Nepali localization
Add i18n support to the frontend (react-i18next or an equivalent lightweight library)
for Story Mode specifically (Explorer and Research modes can remain English-only for
the MVP — state this scope decision in the code comments). Extract all Story Mode
user-facing strings into a translation file structure (en.json, ne.json). Populate
en.json first, then populate ne.json with placeholder machine-translated text ONLY as
a temporary scaffold, and add a prominent TODO comment and a tracked issue flagging that
every string in ne.json must be reviewed by a native Nepali speaker before this is
presented as a real localized feature, not just labeled as one.

Acceptance criteria: switching a language toggle actually changes every visible string
in Story Mode with no leftover English fragments; the ne.json review issue is created
and assigned before this phase is marked complete.
