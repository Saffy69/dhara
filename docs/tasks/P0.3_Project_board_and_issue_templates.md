# P0.3 — Project board and issue templates

P0.3 — Project board and issue templates
Draft a set of GitHub issue templates for this project: "Data pipeline task",
"Frontend task", "Bug", and "Validation task". Each template should require: a one-line
summary, an acceptance criterion, and which of the five weekly milestones (Week 1 through
Week 5, as defined in the DHARA roadmap) it belongs to. Also draft the initial set of
Week 1 issues based on this exit criterion: "a sane displacement time series running on
real data for at least one test patch, for both the Sentinel-1 validation leg and the
NISAR PROVISIONAL live leg." Break that single exit criterion into 6-10 concrete,
independently assignable issues.

Acceptance criteria: every Week 1 issue is small enough that one person could plausibly
finish it in under a day; no issue is vague enough that "done" is ambiguous.
