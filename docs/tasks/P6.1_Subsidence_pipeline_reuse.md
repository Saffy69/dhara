P6.1 — Subsidence pipeline reuse
Re-run the exact same deformation pipeline (P2.1, P3.1, P3.2, P3.3, P3.4) — same code,
not a rewrite — over our second AOI (e.g., Jakarta or Mexico City), using NISAR
PROVISIONAL GUNW data confirmed available via the P1.1 coverage check. The only
difference should be interpretation: reclassify the trend_classification logic so a
long-term steady high-magnitude velocity (rather than a short-term acceleration) is the
signal of interest for subsidence, since subsidence in these cities is typically a
long-term steady process, not a sudden precursor-to-failure signal like a landslide. Set
hazard_type to "land_subsidence" in the resulting Change Passports.

Acceptance criteria: the SAME pipeline codebase (not a parallel copy-pasted version)
produces valid Change Passports for both AOIs, differing only in configuration/
interpretation parameters — if you find yourself duplicating pipeline code to handle
the second AOI, stop and refactor so the AOI and hazard-interpretation logic are
parameters, not forked code paths.
