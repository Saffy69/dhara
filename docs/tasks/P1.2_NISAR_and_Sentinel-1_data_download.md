# P1.2 — NISAR and Sentinel-1 data download

P1.2 — NISAR and Sentinel-1 data download
Extend the coverage-verification script into a download module that pulls the actual
GUNW (and, if coverage allows, GOFF and GCOV) granules for the confirmed date range
over our locked AOI, plus the equivalent Sentinel-1 stack for the historical validation
leg. Store raw downloads in data-pipeline/data/raw/{aoi_name}/{product}/, named with
their acquisition date. Do not re-download a granule that already exists locally.
Log every download with its source URL, maturity level, and CRID/processor baseline
into a manifest file (data-pipeline/data/raw/{aoi_name}/manifest.json) — this manifest
becomes part of every Change Passport's data_provenance field later, so treat it as a
first-class output, not a side effect.

Acceptance criteria: re-running the script twice does not re-download existing files;
the manifest.json is valid JSON and includes, for every granule, its date, product type,
maturity level, and source URL.
