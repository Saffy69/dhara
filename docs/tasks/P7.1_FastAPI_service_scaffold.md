# P7.1 — FastAPI service scaffold

P7.1 — FastAPI service scaffold
Build a FastAPI backend exposing these endpoints, backed by a PostgreSQL database (or
SQLite if the team is very small and time-constrained — document which was chosen and
why):

GET /events?aoi={aoi_name}&hazard_type={type} -> list of Change Passports
GET /events/{event_id} -> full Change Passport JSON
GET /events/{event_id}/timeseries -> per-cluster displacement time series
GET /layers/{layer}/{aoi}/{date} -> pre-rendered raster overlay (PNG/COG)
POST /observations -> community field-report submission
GET /validation/{aoi_name} -> precision/recall/F1 summary from Phase 4

Every response involving a Change Passport must validate against the same JSON Schema
used in the data pipeline (P3.4) — import and reuse that schema definition rather than
re-deriving it, so the pipeline and the API can never silently drift apart.

Acceptance criteria: all endpoints are reachable and return real data pulled from the
actual pipeline output (not hardcoded mock JSON) when tested with a real HTTP client;
an OpenAPI/Swagger doc is auto-generated and reachable at /docs.
