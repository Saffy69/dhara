# P11.1 — Unit tests for the scientific core

P11.1 — Unit tests for the scientific core
Write pytest unit tests for: the coherence masking logic (P2.1) using a small synthetic
raster with known masked/unmasked pixels; the velocity/acceleration fitting (P3.1) using
a synthetic time series with a known, hand-calculated true velocity; the connected-
component clustering (P3.2) using a synthetic binary mask with a known number and size
of connected regions; and the confidence scoring formula (P3.3) using at least 5
synthetic input cases covering High, Moderate, and Low tiers, explicitly asserting the
weighted-sum arithmetic (not just the final tier) is correct.

Acceptance criteria: all tests pass, are runnable via a single `pytest` command from the
data-pipeline directory, and would catch a deliberately introduced bug (verify this by
temporarily breaking the velocity fit and confirming the relevant test fails).
