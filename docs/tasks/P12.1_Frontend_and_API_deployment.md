# P12.1 — Frontend and API deployment

P12.1 — Frontend and API deployment
Deploy the frontend to Vercel or Netlify and the FastAPI backend to a small cloud VM
or serverless platform (Render, Railway, or an equivalent), wiring the frontend's API
base URL to the deployed backend via an environment variable (never hardcode the API
URL in frontend source). Set up a custom or at least memorable subdomain. Confirm CORS
is correctly configured so the deployed frontend can actually reach the deployed API
(this is a common last-mile failure — test it explicitly, don't assume it from local
development working).

Acceptance criteria: the live URL works end-to-end for a fresh visitor with no local
setup, on both desktop and mobile browsers, including a real successful POST to
/observations from the live site (not just from localhost).
