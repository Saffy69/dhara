# P8.3 — Community observation form

P8.3 — Community observation form
Build a simple, mobile-first React form (no app install required, must work on a slow
connection) that lets a user submit a field observation tied to the currently selected
Change Passport (or a free-standing pin drop if no event is selected): a short
description field, an optional contact field, and a submit button that POSTs to
/observations. Show a clear success/failure confirmation. Keep the form's total payload
under 5kb and avoid any heavy JS dependencies for this component specifically, since
it needs to work for users on limited bandwidth in remote areas — this is a real
design constraint, not a nice-to-have.

Acceptance criteria: the form works and submits successfully when tested with browser
dev tools throttled to a slow 2G-equivalent connection; a submission with an empty
description shows a clear inline validation error rather than a failed network request.
