# P3.2 — Event clustering

P3.2 — Event clustering
Write a function that takes the velocity/trend rasters from P3.1, creates a binary mask
of pixels classified "accelerating" whose velocity magnitude exceeds a documented
threshold, and applies scipy.ndimage.label to group connected pixels into discrete
clusters. Drop clusters smaller than a documented minimum area (state the area in both
pixel count and real-world km2, since pixel size varies by product). For each surviving
cluster, compute: centroid (lat/lon), area in km2, mean velocity, and mean coherence
across its pixels.

Acceptance criteria: given real processed data, this produces a list of Python
dictionaries (or a GeoDataFrame), each representing one event cluster with all the
fields above populated with real computed numbers, not placeholders.
