# P11.2 — Integration tests for the API

P11.2 — Integration tests for the API
Write integration tests (using FastAPI's TestClient or an equivalent) covering every
endpoint in P7.1 and P7.2: a happy-path request for each, and at least one deliberately
invalid request per endpoint (bad AOI name, malformed observation payload, non-existent
event_id) confirming a clear, correctly-coded error response rather than a 500 crash.

Acceptance criteria: tests run in CI (wire them into the P0.2 GitHub Actions workflow if
not already covered) and fail loudly if any endpoint starts returning malformed data
relative to the Change Passport JSON Schema.
