# P8.2 — Plain-language passport card component

P8.2 — Plain-language passport card component
Build a reusable React component, PassportCard, that takes a Change Passport JSON
object as a prop and renders it for a non-expert audience: a one-sentence summary of
what changed, a confidence badge (colored by tier, but also always showing the numeric
score and a "why" link that expands to show the five components in plain language, not
just numbers), a short list of "what we checked and ruled out" from
alternative_explanations_checked, and a "suggest what to check next" line from
recommended_next_step. Include the emergency-alert disclaimer in a fixed, always-visible
position on the card, not hidden behind a click.

Acceptance criteria: given any valid Change Passport JSON conforming to the schema in
Part 3, the component renders without errors and never shows raw field names (like
"cross_source_agreement") to the end user without a plain-language label.
