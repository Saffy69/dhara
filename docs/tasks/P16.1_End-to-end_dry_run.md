# P16.1 — End-to-end dry run

P16.1 — End-to-end dry run
Perform a full, timed, start-to-finish run-through of the live demo exactly as it will
be presented to judges, done by someone who will actually present, using the actual
live URL, with no shortcuts or "it'll work on the day" assumptions. Log every point of
friction, confusion, or failure, and fix or explicitly cut each one before the final
week's buffer days run out.

Acceptance criteria: three consecutive successful dry runs with no unplanned errors,
each timed to fit the challenge's presentation time limit.
