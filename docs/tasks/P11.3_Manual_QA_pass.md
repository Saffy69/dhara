# P11.3 — Manual QA pass

P11.3 — Manual QA pass
Perform, and document the results of, a manual QA pass across: a slow-connection
simulation (throttle to slow 3G) for both Story Mode and the observation form; a small
mobile screen width (375px) for all three modes; and a full click-through of every
interactive element in Explorer and Research modes by someone on the team who did NOT
build that specific feature, logging every bug found as a tracked issue before moving
to Phase 12.

Acceptance criteria: a written QA log exists listing what was tested, by whom, and what
was found — not just a verbal "looks fine."
