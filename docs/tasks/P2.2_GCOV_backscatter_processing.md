# P2.2 — GCOV backscatter processing

P2.2 — GCOV backscatter processing
Write a module that reads a NISAR L2 GCOV granule, converts the backscatter power
values to decibels (10*log10(sigma)), and applies valid-data, water, layover, and
shadow masks using whatever quality/flag layers are present in the product. Co-register
onto the same shared grid defined in P2.1. Produce a simple water-extent mask (a
documented backscatter-threshold rule is acceptable for the MVP — state the threshold
and its justification in a code comment) so later change-detection code can track
water/flood extent over time.

Acceptance criteria: dB-converted output falls in a physically sane range (roughly -25
to 5 dB for typical land surfaces); the water mask visibly picks out known rivers/lakes
in the AOI when plotted against a basemap.
