# P10.1 — Provenance and confidence breakdown panel

P10.1 — Provenance and confidence breakdown panel
Build a Research Mode panel that, for a selected Change Passport, displays: the full
data_provenance block (product, maturity, CRID, source URLs as clickable links), the
five confidence components as a labeled bar chart (not just a table of numbers — a
researcher should be able to see at a glance which component is dragging the score
down), and the validation block (whether this event matched a COOLR ground-truth event,
and the detection lead time if applicable).

Acceptance criteria: every source URL is a real, clickable, working link back to the
actual data source (ASF, ESA, USGS, etc.) — no placeholder or dead links; the bar chart
values sum, when weighted per the P3.3 formula, to the displayed overall_score (add an
automated test checking this arithmetic consistency between frontend display and
backend calculation).
