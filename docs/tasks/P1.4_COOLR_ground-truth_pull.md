# P1.4 — COOLR ground-truth pull

P1.4 — COOLR ground-truth pull
Write a function that queries NASA's COOLR (Cooperative Open Online Landslide
Repository) ArcGIS FeatureServer for all catalogued landslide events (both the
report-based Global Landslide Catalog and event-based inventories) within our AOI
bounding box, for all available dates. Save the result as a clean GeoJSON file at
data-pipeline/data/validation/{aoi_name}/coolr_events.geojson, with each feature
retaining its original event date, source citation, and any reported fatality/impact
fields.

Print a summary: how many events, what date range, and whether coverage looks dense
enough to support a meaningful precision/recall calculation later (if fewer than 5
events fall in our AOI/time window, flag this loudly — it changes how confidently we
can present validation statistics).

Acceptance criteria: the GeoJSON is valid, openable in QGIS or a simple matplotlib plot
overlaid on the AOI boundary, and the summary print statement gives an honest count,
not an assumed one.
