# P3.1 — Displacement time series and velocity fitting

P3.1 — Displacement time series and velocity fitting
Given a stack of coherence-masked GUNW displacement rasters (one per acquisition date,
all on the shared grid from P2.1), write a function that, for every valid pixel,
extracts its displacement time series across all dates and fits a simple linear
velocity (mm/year) using least-squares regression. Also compute a second-order fit to
estimate acceleration, and classify each pixel's trend as "accelerating",
"steady", or "decelerating" using a documented, fixed threshold on the quadratic
coefficient (state the threshold value and reasoning in a comment — do not leave it
unexplained).

This function must run efficiently across an entire AOI raster (vectorize with numpy —
do not write a naive per-pixel Python loop over a full-resolution raster; that will be
too slow to iterate on).

Acceptance criteria: running this on real data produces a velocity raster with values
in a physically sane range, and a trend classification raster with all three classes
represented somewhere in the AOI (an AOI showing only one trend everywhere across every
pixel is a red flag worth investigating before proceeding).
