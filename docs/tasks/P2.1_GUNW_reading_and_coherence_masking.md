# P2.1 — GUNW reading and coherence masking

P2.1 — GUNW reading and coherence masking
Write a module that reads a NISAR L2 GUNW HDF5 granule (use h5py) and extracts: the
unwrapped displacement layer, the coherence layer, and the connected-component labels
layer. Apply a coherence mask at a fixed threshold (default 0.3, but make it a named,
documented constant, not a magic number buried in code) — any pixel below this
threshold must be set to NaN/nodata in all derived products, never silently treated as
zero displacement. Reproject/co-register the result onto a single shared grid we'll
reuse across the whole AOI (define this grid once, in one place, and import it
everywhere else in the pipeline — do not let different modules independently
reproject to slightly different grids).

Add a matching reader for the equivalent Sentinel-1-derived interferogram (assume it
arrives in a comparable raster format after an existing SBAS tool has processed it —
document the expected input format clearly as an assumption).

Acceptance criteria: running this on a real downloaded GUNW granule produces a raster
where masked (low-coherence) pixels are visually and numerically distinct (NaN) from
valid pixels, and the coherence threshold is a single named constant that can be
changed in one place.
