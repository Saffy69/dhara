P1.1 — AOI coverage verification (do this before writing any processing code)
Write a Python script using the `asf_search` package that, given a bounding box and a
date range, checks and reports:
1. Available Sentinel-1 SLC or GUNW-equivalent products covering that bbox, with dates.
2. Available NISAR L2 GUNW, GOFF, and GCOV products at PROVISIONAL maturity or better
   covering that bbox, with dates and processor/CRID metadata if present in the search
   result.
Do NOT assume both datasets exist — the script's job is to tell us the truth about
coverage, including printing a clear "INSUFFICIENT COVERAGE" warning if either dataset
has fewer than 4 acquisitions in the window, since a usable time series needs several
repeat passes.

Run this for two candidate bounding boxes: (1) the Sindhupalchowk/Melamchi watershed
corridor, Nepal, and (2) [insert your chosen global subsidence AOI, e.g. Jakarta,
Indonesia]. Print a clear summary table for each.

Acceptance criteria: the script runs against the real ASF API (not mocked data) and
produces a coverage report you can act on immediately — if either AOI shows
"INSUFFICIENT COVERAGE", say so plainly rather than proceeding optimistically.
