# P1.3 — Ancillary data (rainfall, DEM, seismic)

P1.3 — Ancillary data (rainfall, DEM, seismic)
Add three acquisition functions to the data pipeline:
1. Pull GPM IMERG daily precipitation for our AOI and date range (use the NASA GES DISC
   API or an equivalent public endpoint).
2. Pull a Copernicus GLO-30 DEM tile (or tiles) covering the AOI, and derive slope and
   aspect rasters from it using rasterio/richdem.
3. Query the USGS earthquake catalog API for all events above magnitude 4.5 within
   200km of the AOI centroid, going back 20 years.
Save each as a clearly named file under data-pipeline/data/ancillary/{aoi_name}/, and
log each source (URL, query parameters, retrieval date) into the same manifest pattern
as P1.2.

Acceptance criteria: all three ancillary datasets exist as real files derived from real
API calls (not synthetic placeholder data); the slope/aspect rasters are visually
sane when plotted (mountainous AOI should show a wide slope distribution, not a flat
image).
