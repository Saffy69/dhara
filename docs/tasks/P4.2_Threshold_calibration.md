# P4.2 — Threshold calibration

P4.2 — Threshold calibration
Using the precision/recall evaluation from P4.1 as a scoring function, write a small
grid-search or sweep script that tries a documented range of values for the coherence
mask threshold (from P2.1) and the acceleration/velocity thresholds (from P3.2), and
reports which combination maximizes a reasonable balance of precision and recall (e.g.
F1 score) on the validation set. Do NOT auto-apply the winning thresholds silently —
print a clear before/after comparison and require a manual confirmation step before
updating the production constants, since overfitting five hyperparameters to a handful
of COOLR events is a real risk worth being conscious of and stating honestly in the
methodology writeup.

Acceptance criteria: the sweep runs against real validation data and produces a
readable table of threshold combinations vs. resulting precision/recall/F1; the
methodology doc (Phase 15) explicitly discusses the risk of overfitting to a small
validation set.
