P5.3 — Soil moisture corroboration layer
If NISAR SME2 coverage exists for the AOI (verify with asf_search first — do not
assume), read the field-scale soil moisture product and feed it into the
cross_source_agreement component of the confidence model (P3.3) as a fourth
corroborating check alongside rainfall, slope, and seismic history — update the
weighting/scoring logic in P3.3 accordingly and document the change. If SME2 coverage
does NOT exist for this AOI, do not fabricate this layer — instead, write a short,
clear note in the methodology doc stating that SME2 was evaluated and found
insufficiently covered for this AOI/time window, and that this is a documented
limitation, not an oversight.

Acceptance criteria: either a real SME2-based corroboration check exists and is used
in at least one real Change Passport, or a clear, honest documentation note exists
explaining why it doesn't.
