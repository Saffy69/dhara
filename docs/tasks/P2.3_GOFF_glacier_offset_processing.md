# P2.3 — GOFF glacier offset processing

P2.3 — GOFF glacier offset processing
Write a module that reads a NISAR L2 GOFF granule, extracts along-track and slant-range
pixel offsets plus their correlation/variance quality layers, and rejects offsets below
a documented correlation threshold. Convert offset-per-acquisition-interval into a
velocity estimate only when the exact time interval between the two source acquisitions
is known and stored — never silently assume a fixed interval. Store direction and an
uncertainty estimate alongside the velocity value, and co-register onto the shared grid.

Acceptance criteria: velocity estimates over a known glacier terminus in the AOI (or
nearest available glacier if the flagship AOI itself has none) fall within a physically
plausible range (typically single-digit to tens of meters per year for Himalayan
glaciers — flag anything wildly outside that range as a likely processing error rather
than reporting it uncritically).
