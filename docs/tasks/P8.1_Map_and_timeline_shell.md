# P8.1 — Map and timeline shell

P8.1 — Map and timeline shell
Build a React + TypeScript page using MapLibre GL JS, centered on the flagship Nepal
AOI, with: a time slider along the bottom controlling which date's overlay layer is
shown (fetched from GET /layers/{layer}/{aoi}/{date}), and clickable markers for every
Change Passport returned by GET /events?aoi=nepal_flagship. Clicking a marker opens a
side panel showing the Change Passport rendered in plain language (not raw JSON): what
changed, the confidence tier with a short one-line plain-English explanation of what
that tier means, and a clearly visible "This is not an emergency alert" line.

Acceptance criteria: the page loads real data from the real backend (not a mocked
fixture) and correctly updates the map overlay when the time slider moves; every
displayed Change Passport correctly reflects the underlying JSON, with no
hallucinated or hardcoded example data left in the final build.
