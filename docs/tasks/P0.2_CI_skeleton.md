# P0.2 — CI skeleton

P0.2 — CI skeleton
Add a GitHub Actions workflow at .github/workflows/ci.yml that, on every pull request:
1. Installs Python dependencies in /data-pipeline and /api and runs pytest.
2. Installs Node dependencies in /frontend and runs its test suite and a production build.
3. Fails the check if either step fails.
Keep it simple — no deployment steps here, just test-and-build verification. Document
in CONTRIBUTING.md that PRs cannot merge unless this check is green.

Acceptance criteria: pushing a deliberately broken test causes the Action to fail and
show a clear error in the GitHub UI; a clean PR passes in under 5 minutes.
