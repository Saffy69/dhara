P13.2 — README and architecture diagram
Write a top-level README.md that a judge unfamiliar with the project could read in
under 3 minutes and understand: what DHARA does, why it matters (with the real cited
2015/2021 Nepal events), how to run it locally, a link to the live deployed demo, and
a link to docs/METHODOLOGY.md. Include a clear architecture diagram (can be a
text/ASCII diagram like the one in this document's Part 4, or a rendered image) showing
data flow from NISAR/Sentinel-1 through to the frontend.

Acceptance criteria: someone outside the team, given only this README, can find the
live demo link and understand the project's core claim without needing to ask a
question.
